# ImageMerge v2

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![Version](https://img.shields.io/badge/version-2.0.0-green.svg)
![Status](https://img.shields.io/badge/status-stable-success.svg)

**ImageMerge v2** is a high-performance web application that reconstructs images using the pixels of another image. It features a smooth user interface and a built-in image converter.

## ✨ Features

- **Pixel Reconstruction**: Recreates a target image using the color palette of a source image.
- **High Performance**: Optimized algorithm for fast processing (O(N²/2) complexity).
- **Professional UI**: Modern dark mode design with glassmorphism effects.
- **Interactive Background**: 3D particle system powered by **Three.js**.
- **Audio Feedback**: Immersive sound effects using the **Web Audio API**.
- **Animation**: Visualize the reconstruction process in real-time.
- **Export**: Download the result as a high-quality PNG.

## 🚀 How to Use

1.  **Select Source Image**: Choose the image that will provide the color palette.
2.  **Select Target Image**: Choose the image you want to reconstruct.
3.  **Adjust Settings**:
    *   **Downscale Factor**: Higher values mean faster processing but lower resolution.
    *   **Animation Resolution**: Controls the block size for the animation.
4.  **Run**: Click "Start Processing" to begin.
5.  **Download**: Save your creation once complete.

## 🛠️ Tech Stack

- **Core**: HTML5, CSS3, Vanilla JavaScript
- **Graphics**: HTML5 Canvas, Three.js
- **Audio**: Web Audio API
- **Styling**: CSS Variables, Backdrop Filter (Glassmorphism)
